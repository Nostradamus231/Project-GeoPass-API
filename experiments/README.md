# Вычислительный эксперимент: сравнение методов оценки средних мощностей и запасов месторождений

Воспроизводимый численный эксперимент для научной статьи (журнал «Наука», КИнЭУ), сопоставляющий метод простого среднего арифметического и метод взвешивания по площадям влияния скважин (полигоны Вороного, обрезанные границами горного отвода).

> **Важное уведомление**: все данные эксперимента являются полностью **синтетическими**, детерминированно сгенерированными на основе математических моделей пространственной изменчивости. Реальные геологоразведочные данные не использовались.

---

## 1. Научные гипотезы

* **H0 (нулевая гипотеза)**: при неравномерной сети разведочных скважин точность и смещение оценки геологических запасов методами простого арифметического осреднения и взвешивания по полигонам Вороного статистически не различаются.
* **H1 (альтернативная гипотеза)**: взвешивание мощностей по площадям ячеек Вороного, усечённых внешним контуром месторождения, статистически значимо снижает смещение (bias) и среднеквадратичную ошибку (RMSE) оценки запасов по сравнению со средним арифметическим в условиях неравномерных сетей (пространственная кластеризация, селективное/преференциальное сгущение скважин в зонах повышенной мощности пласта). При квазирегулярной сети различия между методами практически нивелируются.

---

## 2. Математическая модель залежи

Поле мощности $T(x, y)$ [м] строится детерминированно по заданному зерну генератора случайных чисел (`seed`) без использования сторонних ML-библиотек:
1. **Линейный региональный тренд**: $t_x (x - x_0) + t_y (y - y_0)$.
2. **Гауссовы морфологические линзы**: 3–5 эллиптических неоднородностей вида:
   $$A_k \exp\left( -\frac{(x - x_k)^2}{2\sigma_{xk}^2} - \frac{(y - y_k)^2}{2\sigma_{yk}^2} \right)$$
3. **Мелкомасштабная вариация**: суперпозиция 12 спектральных гармоник Фурье со случайными фазами и направлениями.
4. **Калибровка и срез**: поле обрезается снизу на технологический минимум $T \ge 0,5$ м и масштабируется до достижения целевого коэффициента вариации (CV).

### Сценарии изменчивости (CV)
* **cv_low**: низкая изменчивость ($\text{CV} \approx 10\%$, целевой 0,10);
* **cv_med**: умеренная изменчивость ($\text{CV} \approx 25\%$, целевой 0,25);
* **cv_high**: высокая изменчивость ($\text{CV} \approx 50\%$, целевой 0,50).

### Эталонные значения (Ground Truth)
Истинные средняя мощность и балансовые запасы вычисляются аналитической интеграцией по регулярной сетке с шагом 5 м:
$$\bar{T}_{\text{true}} = \frac{1}{N_{\text{grid}}} \sum_{i \in \Omega} T(x_i, y_i), \quad Q_{\text{true}} = S \cdot \bar{T}_{\text{true}} \cdot \rho$$
где $S$ — точная геометрическая площадь контура, $\rho = 1,6$ т/м³ — фиксированная плотность полезного ископаемого.

### Геометрические контуры
1. **rect**: прямоугольный полигон $1000 \times 800$ м ($S = 800\,000$ м², 80 га);
2. **poly**: невыпуклый/скошенный шестиугольный выпуклый контур ($S = 693\,750$ м², 69,38 га) для проверки геометрической робастности.

## 3. Модели сетей разведочных скважин

Для каждого прогона формируется сеть из $n \in \{8, 12, 16, 24, 36\}$ скважин с соблюдением минимального расстояния между устьями $\ge 5$ м:
1. **regular**: квазирегулярная прямоугольная сеть с контролируемым случайным смещением узлов ($\le 10\%$ шага сетки);
2. **random**: независимое равномерное случайное распределение скважин внутри контура;
3. **clustered**: скважины концентрируются в 2–3 кластерах ($\approx 70\%$ точек вокруг случайных центров с нормальным рассеянием $\sigma \approx 50$ м), остальные $\approx 30\%$ равномерно рассеяны по площади;
4. **preferential_k1**: селективное разведочное сгущение первой степени — плотность вероятности размещения скважины пропорциональна мощности $T(x, y)$;
5. **preferential_k2**: квадратичное преференциальное сгущение — плотность вероятности пропорциональна $T(x, y)^2$ (имитирует разведку богатых участков эксплуатационными блоками).

---

## 4. Методы оценки и статистика

### Оценщики
* **Арифметический (`arith`)**: простое среднее значений по скважинам:
  $$\bar{T}_{\text{arith}} = \frac{1}{n} \sum_{i=1}^n T_i, \quad Q_{\text{arith}} = S \cdot \bar{T}_{\text{arith}} \cdot \rho$$
* **Метод полигонов Вороного (`voronoi`)**: средневзвешенное по площадям влияния ячеек, усечённых полигоном контура:
  $$\bar{T}_{\text{voronoi}} = \frac{1}{S} \sum_{i=1}^n S_i T_i, \quad \sum_{i=1}^n S_i = S, \quad Q_{\text{voronoi}} = S \cdot \bar{T}_{\text{voronoi}} \cdot \rho$$

### Относительная погрешность
$$e = \frac{Q_{\text{est}} - Q_{\text{true}}}{Q_{\text{true}}}$$

### Метрики качества
* **Смещение (Bias)**: $\mathbb{E}[e]$;
* **RMSE**: $\sqrt{\mathbb{E}[e^2]}$;
* **MAE**: медиана $|e|$;
* **P95**: 95-й перцентиль абсолютной ошибки $|e|$;
* **Доля выигрыша Voronoi (Win Rate)**: доля прогонов, в которых $|e_{\text{voronoi}}| < |e_{\text{arith}}|$;
* **Парный бутстреп (5 000 повторов)**: 95%-й доверительный интервал для разности RMSE ($\Delta\text{RMSE} = \text{RMSE}_{\text{arith}} - \text{RMSE}_{\text{voronoi}}$) и смещения ($\Delta\text{Bias}$);
* **Знаковый критерий (Sign Test)**: точное двустороннее $p$-значение парной разности по биномиальному распределению.

## 5. План эксперимента и воспроизводимость

* Факторный план: 3 сценария CV $\times$ 2 контура $\times$ 5 типов сетей $\times$ 5 значений $n$ = **150 уникальных комбинаций факторов**;
* Количество повторов: **1 000** независимых генераций залежи и сети на каждую комбинацию (всего **150 000** численных прогонов);
* Все генераторы инициализируются фиксированным мастер-зерном (`seed = 20261025`), что гарантирует побитовую повторяемость результатов.

### Команды запуска

Быстрый тестовый прогон (50 повторов):
```powershell
.\venv\Scripts\python.exe -m experiments.run_experiment --quick --seed 1 --out results
```

Полный исследовательский эксперимент (1 000 повторов, 12 параллельных потоков):
```powershell
.\venv\Scripts\python.exe -m experiments.run_experiment --repeats 1000 --seed 20261025 --out results
```

Генерация журнальных иллюстраций (300 DPI, JPEG):
```powershell
.\venv\Scripts\python.exe -m experiments.make_figures
```

## 7. Принятые допущения и ограничения модели

1. **Изотропия поля**: автокорреляция параметров мощности принята квазиизотропной; анизотропия рудных столбов не моделировалась.
2. **Сплошность продуктивной толщи**: модель предполагает непрерывный пласт без тектонических разломов, зон выклинивания или эрозионных размывов.
3. **Отсутствие маркшейдерских ошибок**: координаты скважин и замеры мощностей в базовом расчёте считаются свободными от инструментальных погрешностей позиционирования.
4. **Простая геометрия границы**: границы отвода аппроксимируются выпуклыми многоугольниками без острых заливов и анклавов.
